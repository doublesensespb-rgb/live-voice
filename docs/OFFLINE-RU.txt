2. БЫСТРЫЙ СТАРТ
──────────────────────────────────────────────────────────────────────────────
  1) Распаковать builds\LIVE-VOICE-0.13-Windows.zip в любую папку (например, Рабочий стол).
  2) Запустить "LIVE VOICE.exe".
     Синее окно "Windows защитил ваш компьютер" -> "Подробнее" -> "Выполнить в любом случае"
     (программа не подписана платным сертификатом — это нормально).
  3) При первом запуске само откроется окно AUDIO:
       Audio device type : "Windows Audio (Low Latency Mode)" (если есть), иначе "Windows Audio"
       Input             : микрофон (USB-микрофон / вход звуковой карты)
       Output            : наушники / колонки / выход на пульт
     Закрыть окно. Всё запомнится. Дальше — просто запускать.
  4) Говорить в микрофон — голос уже обработан (режим RADIO).

  Кнопка AUDIO вверху — открыть это окно ещё раз (сменить микрофон/выход).

3. УПРАВЛЕНИЕ  (0.13)
──────────────────────────────────────────────────────────────────────────────
  При запуске видны ТОЛЬКО 10 пресетов (настройки спрятаны). Справа узкая вкладка
  "SHOW PITCH & EFFECTS" (или клавиша H) открывает модуль PITCH + EFFECTS; кнопка HIDE в его углу — прячет.
  Программа помнит, открыт модуль или нет.

  VOICE PRESETS — готовый "коммерческий" звук: улучшение + насколько ниже + клиппер + эффекты.
  Цифра и полоска на плитке = насколько голос ниже. Клавиши 1…9 и 0 = плитки по порядку.
    1 CLEAN ...... 0   натурально, без эффектов
    2 RADIO ...... 0   плотный FM-ведущий            WIDE 20 %
    3 CLUB MC .... 0   режет громкую музыку          WIDE 20 %
    4 WARM ...... -2   близко и бархатно             WIDE 25 %
    5 DEEP ...... -4   глубокий диктор               WIDE 25 %
    6 BIG HOST .. -6   "стадионный" голос            WIDE 30 %
    7 GIANT ..... -9   тяжёлый, тёмный               WIDE 20 % + BRUTAL 25 %
    8 TITAN .... -12   самый низкий                  WIDE 20 % + BRUTAL 35 %
    9 TRAILER ... -5   голос из трейлера             WIDE 25 % + BRUTAL 50 % + ECHO 15 %
    0 HYPE MC .... 0   клубный ведущий               WIDE 25 % + ECHO 40 %

  PITCH — большая ручка: влево ниже и мощнее, вправо выше. Пресет сам ставит ручку.
    Двойной клик — вернуть как в пресете. Стрелки ВВЕРХ/ВНИЗ — шаг.

  EFFECTS — можно включать ВМЕСТЕ, у каждого своя полоска силы:
    WIDE ..... ширина и "вкус". Безопасен для моно-зала: в моно расширение исчезает, голос остаётся чистым.
    SHIMMER .. сияние на октаву выше (для спецмоментов, на речи размывает слова).
    ECHO ..... эхо, последнее слово улетает в зал; пока говоришь — эхо тише.
    BRUTAL ... "тяжёлый ведущий": масса голоса ниже + хрипотца в середине + грудь. Без "робота".

  ВЕРХНЯЯ ПОЛОСА: IN/OUT индикаторы, CLIP (C) клиппер, ON (ПРОБЕЛ), AUDIO, MUTE (M).

  Шум: программа сама слушает фон комнаты и в паузах убирает его (даже после компрессора).
  При понижении голоса верха (чёткость, "воздух") берутся из оригинального голоса.

──────────────────────────────────────────────────────────────────────────────
4. КАК СЛЫШАТЬ СЕБЯ И ЧТОБЫ НЕ БЫЛО ПИСКА (ЗАВЯЗКИ)
──────────────────────────────────────────────────────────────────────────────
  Писк/свист = микрофон слышит колонку, колонка играет микрофон — круг.

  ДОМА / ДЛЯ ТЕСТА
    • Слушать В НАУШНИКАХ — писка не будет вообще.
    • Отключить прослушку Windows (иначе голос звучит дважды — сырой и обработанный):
      Параметры -> Система -> Звук -> (микрофон) -> Свойства устройства -> Дополнительные
      свойства -> вкладка "Прослушать" -> СНЯТЬ галочку "Прослушивать с данного устройства".
      (Старый путь: Панель управления -> Звук -> Запись -> микрофон -> Свойства -> Прослушать.)
    • Если только колонки: колонки тише, микрофон отвернуть от колонок, говорить близко (5–10 см).

  НА МЕРОПРИЯТИИ
    • Порталы (главные колонки) — ПЕРЕД ведущим, ведущий за линией колонок.
    • Мониторы — сбоку или сзади микрофона, не "в лицо" микрофону.
    • Динамический микрофон (типа Shure SM58) завязывается гораздо меньше конденсаторного.
    • Говорить близко к микрофону — тогда пульт/LEVEL можно держать ниже.
    • Сильные эффекты (SHIMMER, ECHO на 100 %) и режим CLUB легче доводят до свиста —
      не выкручивать их у колонок.
    • Засвистело -> M (MUTE) -> убавить LEVEL или громкость на пульте -> снять MUTE.


──────────────────────────────────────────────────────────────────────────────
5. ЗАДЕРЖКА — КАК СДЕЛАТЬ МИНИМАЛЬНОЙ
──────────────────────────────────────────────────────────────────────────────
  • Пресеты без понижения (PITCH = 0, без BRUTAL) -> обработка БЕЗ задержки.
  • Понижение или BRUTAL -> +30 мс (так устроен сдвиг голоса; в зале незаметно —
    звук от колонки до ведущего на 10 метров идёт столько же).
  • Остальное — задержка звуковой карты. Чтобы уменьшить:
      1) В окне AUDIO выбрать "Windows Audio (Low Latency Mode)".
      2) Лучше всего — внешняя звуковая карта с драйвером ASIO (Focusrite, Steinberg, Audient...):
         в AUDIO выбрать тип "ASIO", буфер 128 (если трещит — 256).
      3) USB-микрофон обычно даёт 15–30 мс сам по себе — для ведущего это нормально.
  • Если звук трещит/щёлкает — УВЕЛИЧИТЬ буфер (Audio buffer size) в окне AUDIO.

6. ПРЕСЕТЫ И НАСТРОЙКИ — ГДЕ ЛЕЖАТ
──────────────────────────────────────────────────────────────────────────────
  Пресеты встроены в программу (10 плиток), отдельных файлов больше нет.
  Настройки: %APPDATA%\LIVE VOICE\LIVE VOICE.settings
             (выбранные микрофон/выход и последнее состояние ручек).
             СБРОС ВСЕГО: закрыть программу, удалить этот файл, запустить снова
             (снова откроется окно AUDIO как при первом запуске).
  Чтобы открыть %APPDATA%: Win+R -> ввести %APPDATA% -> Enter.

7. ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
──────────────────────────────────────────────────────────────────────────────
  Нет звука вообще
    • Индикатор IN не двигается -> не тот микрофон: AUDIO -> Input. Проверить, что микрофон
      включён в Windows: Параметры -> Конфиденциальность -> Микрофон -> разрешить
      "классическим приложениям" доступ к микрофону.
    • IN двигается, OUT нет -> нажат MUTE (красный) или LEVEL на минимуме.
    • OUT двигается, но не слышно -> не тот выход: AUDIO -> Output.
    • Вход занят другой программой (Zoom, Discord, OBS) -> закрыть её или выбрать
      "Windows Audio" вместо Low Latency Mode.
  Шум/гул в паузах
    • Программе нужно ~2 секунды тишины, чтобы "услышать" фон комнаты — дальше паузы чистые.
  Обрезаются тихие слова
    • Говорить ближе к микрофону; в очень шумном зале гейт держит порог выше.
  Голос звучит дважды / с эхом без эффектов
    • Включена прослушка Windows (см. раздел 4) или пульт получает и сырой микрофон тоже.
  Трещит, щёлкает
    • Увеличить буфер в AUDIO. Закрыть тяжёлые программы. Ноутбук — от сети, режим
      "Максимальная производительность".
  Тихо
    • Авто-уровень сам поднимает тихий микрофон за несколько секунд речи.
      Если всё равно тихо — LEVEL вправо или поднять уровень микрофона в Windows.
  Слишком громко / красное на OUT
    • LEVEL влево. Лимитер не даст перегрузить пульт, но лучше держать без красного.
  Окно AUDIO не открывается / программа не стартует
    • Удалить файл настроек (раздел 6) и запустить снова.
    • Запущена вторая копия — работает только одна (две бы дрались за микрофон).

9. КАК СОБРАТЬ ПРОГРАММУ САМОМУ (БЕЗ ИНТЕРНЕТА)
──────────────────────────────────────────────────────────────────────────────
  ВАЖНО: две программы нужно установить ЗАРАНЕЕ, пока есть интернет:
    • Visual Studio 2022 Community — компонент "Разработка классических приложений на C++"
      https://visualstudio.microsoft.com/ru/vs/community/
    • CMake (Windows x64 Installer, при установке отметить "Add CMake to PATH")
      https://cmake.org/download/
    (Можно сделать установщик Visual Studio, работающий без интернета: "offline layout",
     инструкция: https://learn.microsoft.com/visualstudio/install/create-an-offline-installation-of-visual-studio)

  Всё остальное (JUCE, библиотеки, шрифты) уже лежит в офлайн-архиве.

  СБОРКА
    1) Распаковать офлайн-архив, например в C:\LIVE-VOICE\ (короткий путь без русских букв!).
    2) Дважды кликнуть tools\build-windows.bat. Ждать 5–15 минут.
    3) Готовая программа: build\LiveVoice_artefacts\Release\Standalone\LIVE VOICE.exe

  ПОМЕНЯТЬ НОМЕР ВЕРСИИ: в CMakeLists.txt строки
      project(LiveVoice VERSION 0.1.3)    ->  например 0.1.4
      set(LIVEVOICE_LABEL "0.13")         ->  например "0.14"

  ПРОВЕРИТЬ ЗВУКОВОЙ ДВИЖОК (тесты): после сборки с целью DspTest
      cmake --build build --config Release --target DspTest
      затем запустить build\Release\DspTest.exe — в конце должно быть "ALL TESTS PASSED".

10. КАК ПРОДОЛЖИТЬ РАЗРАБОТКУ (С ДРУГИМ ИИ ИЛИ ПРОГРАММИСТОМ)
──────────────────────────────────────────────────────────────────────────────
  • Дать ему ВЕСЬ офлайн-архив и сказать: "Прочитай AGENTS.md целиком, потом делай правки".
    В AGENTS.md описано: устройство кода, правила (что нельзя менять), дизайн, сборка, история.
  • Главные правила, чтобы ничего не сломать:
      - не переименовывать ID параметров (voiceOn, mode, strength, pitch, formant, sfxOn,
        sfxType, sfxAmount, mute, output) — иначе сломаются пресеты и сохранённые настройки;
      - большая ручка PITCH в интерфейсе = параметр "formant" (так задумано с 0.11);
      - не добавлять обработку с задержкой в прямой путь голоса;
      - дизайн GRAPHITE: графит + медь, шрифт Inter, строгие иконки.
  • История: в папке есть .git — любой программист увидит каждую версию
    (команда: git log). Вернуться к старой версии: git checkout <номер-коммита>.
  • Когда появится интернет: залить изменения на GitHub в ветку main —
    сборка запустится сама и положит готовый архив в ветку builds.

11. КАК УСТРОЕН ЗВУК (ДЛЯ СПЕЦИАЛИСТОВ)
──────────────────────────────────────────────────────────────────────────────
  Микрофон -> срез низа (80–140 Гц, 24 дБ/окт) -> умный гейт (порог = шум комнаты +13 дБ, 1:5,
  удержание 120 мс) -> авто-уровень (медленный, только во время речи, -6…+12 дБ) ->
  PITCH (Signalsmith Stretch, блок 30 мс; при 0 — прямой путь без задержки; выше 4.5 кГц —
  верха оригинального голоса) + слой BRUTAL ->
  чистка 250–420 Гц -> компрессор (2.5–6:1, быстрая атака) -> тело (low shelf) /
  присутствие 3–4.2 кГц / воздух 10 кГц -> де-эссер (5–8 кГц) -> теплота (tanh) ->
  повторное подавление шума в паузах ->
  WIDE (только боковое стерео, моно-безопасный) + ECHO + SHIMMER -> CLIP (tanh + сглаживание ADAA, без задержки) -> LEVEL -> MUTE -> лимитер -1 dBFS + мягкий клип.
  Нагрузка на процессор: 2–7 % одного ядра. Работает на 44.1 / 48 / 96 кГц.

12. ИСТОРИЯ ВЕРСИЙ
──────────────────────────────────────────────────────────────────────────────
  0.1  — первая версия: 4 режима, PITCH + FORMANT, SFX (WIDE, SHIMMER, ECHO THROW, BRUTAL),
         пресеты (6 заводских), UNDO, прямой путь без задержки, авто-уровень, дизайн GRAPHITE.
  0.13 — эффекты включаются вместе (у каждого своя сила); WIDE безопасен для моно и немного включён
         во всех пресетах, кроме CLEAN; новый BRUTAL ("тяжёлый ведущий" вместо октавы вниз);
         PITCH и EFFECTS в одном модуле, кнопка HIDE; при запуске видны только пресеты.
  0.12 — СУПЕР-ПРОСТОЙ интерфейс по просьбе заказчика: 10 готовых пресетов-плиток (улучшение +
         разное понижение + клиппер + иногда эффект), ручка PITCH, 4 кнопки эффектов, кнопка CLIP.
         Убраны: режимы, STRENGTH, SAVE/UNDO, свои пресеты. Шум в паузах больше не растёт
         (умный гейт + подавление после компрессора). При понижении верха голоса сохраняются.
  0.11 — большая ручка PITCH теперь делает то, что раньше делал FORMANT (меняет "размер"
         голоса — именно это звучит как "опустил голос"). Старый сдвиг ноты убран
         (на речи почти не слышен и давал шелест). Заводские пресеты перенастроены.
